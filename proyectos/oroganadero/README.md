# OroGanadero

| Campo | Dato |
|---|---|
| Competencia | Hackathon Enactus 2026 |
| Fecha y sede | CDMX, 2 al 6 de mayo de 2026 |
| Equipo y mi rol | Con Jesús y Sara — mi rol: entrenador de modelos |
| Reconocimiento | Participación |
| Stack | Swift, AVFoundation, Vision, Core Location, Foundation Models |

**Problema:** El estiércol que generan los ranchos ganaderos no tiene un canal directo hacia quienes pueden procesarlo.

**Solución:** App iOS que conecta a ganaderos con plantas de procesamiento de estiércol.
